# LaTeX-dump
LaTeX source files.

Very much a barebones layout for tyj.sty, probably because I don't have much of a function for it yet. So far I only have the `pset` option, which just includes a nice cover page and some theorem environments. 

Refer to tryout\[X\].pdf and tryout\[X\].tex to see how the package's used. X here refers to the latest version number.
